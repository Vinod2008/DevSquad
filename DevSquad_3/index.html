<img> Image Tag

Used to embed images on web pages. It is a self-closing tag that does not require a closing tag.

src="..." Attribute

Specifies the source path or URL of the image file to display on screen.

alt="..." Attribute

Provides alternate descriptive text for accessibility or if the image fails to load.

Specifies the URL location of the audio file to load and play.
