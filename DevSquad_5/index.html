Unique Identifier

An id must be completely unique within an HTML page. No two elements can share the same ID name.You can name it anything.

Case Sensitive

IDs are case-sensitive and must not contain spaces (use hyphens like main-header instead).

CSS Selector: #

In CSS, an ID is targeted using the hashtag symbol (e.g., #main-header). It's like our class only, we give a id to each student, for its identity.similarly in this we give id to each element we have to give/select.

Definition

In HTML, a class is an attribute used to assign one or more names to an element, allowing it to be styled with CSS or accessed via JavaScript.

Multiple Classes

An element can have multiple classes separated by spaces (e.g., class="card-text highlight").

CSS Selector: .

In CSS, a class is targeted using a dot prefix (e.g., .card-title).

Best Practice

Use id for unique structural elements (Header, Footer, Navbar) or JavaScript hooks.

Styling Rule

Use class for styling repeated components like buttons, cards, and text styles.

Note

An element can have both an id and one or more class attributes at the same time!
