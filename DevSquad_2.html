<b> Bold Tag

Makes text bold to draw visual attention without adding extra importance. It is a paired tag requiring a closing </b> tag.

<i> Italic Tag

Displays text in an italicized style. Used for technical terms, foreign phrases, thoughts, or titles. Paired tag requiring </i>.

<u> Underline Tag

Renders text with a line beneath it. Useful for highlighting key words or annotations. Paired tag requiring </u>.

Chapter 2

<hr> Horizontal Rule

Creates a horizontal divider line. Used to represent a thematic break between paragraphs or topics.

Self-Closing / Empty Tag

Does NOT need a closing tag (unlike <b> or <i>). It is written as <hr> or <hr />.

Separator

Visually breaks up content to improve readability when transitioning between chapters, sections, topics or paragaraphs.
