<ul> Tag

Creates bulleted (unordered) items where sequence order doesn't matter.

<ol> Tag

Creates numbered (ordered) items used when step sequence or priority matters.

<li> Tag

Represents individual List Items inside both <ul> and <ol> parents.

Definition

A list within another list is called a nested list. It can be used to represent hierarchical data or subcategories.

Mixed Types

Mix ordered <ol> and unordered <ul> lists freely depending on sub-item context.

Navigation Trees

Essential foundation for dropdown menus, navigation bars, and multi-level sitemaps.

<table> Tag

Main wrapper element used to declare a structured tabular dataset.

<tr> Tag

Table Row - creates a horizontal container for data cells and headers.

<th> & <td> Tags

<th> holds bold centered header cells; <td> holds standard table data cells.
